# Document Ghost Swamp

A walk through Louisiana folklore, cryptids, and bayou creatures.  
Collect, read, and wander until dark.

Free browser game — document legends, cabin notes, and field pages as day turns to night.

The first game I ever made.

**What makes it different**
- Not a shoot-’em-up — observational and educational
- Real Louisiana folklore and cryptids
- Day softens into night; some things only appear after dark
